# 未決事項

決まっていないこと、および決めるために必要な情報。
解決したら `decisions.md` に `D-xxx` として移し、ここには `→ D-xxx` と残す。

書式：

- **問い** … 何が決まっていないか
- **必要な情報** … 決めるために何を調べる/確認する必要があるか
- **ブロックするもの** … これが未決だと何が進まないか
- **状態** … `Open` / `Resolved → D-xxx`

## Q-001 無料ソースのスクレイピングは利用規約上許容されるか

**状態**: Open ／ **優先度: 最高（着手のブロッカー）**

**必要な情報**:

**ブロックするもの**: `P-0` のローダー実装全体。

**備考**: 規約上不可の場合、`D-005` を見直してJRDBを前倒しで導入する必要がある。その場合Phase 1〜3の着手コストが上がるが、データ品質と収集速度は改善する。
実施する場合は、レート制限とローカルキャッシュを**最初から**実装に組み込む前提とする。20年分は数万ページ規模になる。

## Q-006 過去オッズの利用範囲をどこまで許すか

**状態**: Open

**問い**: `D-002` は「予測対象レースのオッズを使わない」と定めたが、`F-701`（騎手の交絡除去）は過去レースのオッズ（人気）を使う。この線引きをどこまで広げるか。

**論点**:
- 騎手・厩舎の実力推定に過去人気を使うのは、交絡除去として正当と考えられる
- しかし同じ論法で「馬の過去人気」「種牡馬の過去人気」まで使い始めると、モデルは実質的に市場のコピーに近づく
- 市場情報の混入度合いを測る手段が必要

**暫定方針**: 過去オッズの利用は `F-701`（騎手）と `F-703`（厩舎）に限定する。それ以外での使用は都度 `D-xxx` を起こして判断する。

**検証方法の案**: 過去オッズを使う特徴量を含むモデルと含まないモデルの両方を作り、市場確率との相関を比較する。

## Q-010 `003-features.md` を特徴量群ごとに分割するか

**状態**: Open

**問い**: `F-301`（馬場差推定）を `013` に切り出した結果、`003-features.md` の残りは `F-1xx`〜`F-9xx`（`F-3xx` の一部を除く）となる。これを1本のまま書くか、特徴量群ごとにさらに分割するか。

**論点**:
- 1本にまとめると、`F-1xx`（展開）から `F-9xx`（横断処理）まで性質の違うものが同居し、肥大化する
- 分割すると、`F-901`（レース内相対化）や `F-902`（縮約）のような**全特徴量に適用される横断規約**の置き場所が問題になる。各ファイルに重複させると規約が分裂する
- `D-013` の基準に照らすと、`F-1xx` と `F-2xx` は「別の人が別のタイミングで実装しうる」に当たる

**必要な情報**: `003` を実際に書き始めて、1本での分量が保守可能な範囲に収まるかを見る。

**ブロックするもの**: 特にない。`003` の執筆を始めた時点で判断できる。

**暫定方針**: まず1本で書き始め、横断規約（`F-9xx`）を冒頭の共通節に置く。分量が保守困難になった時点で分割し、そのとき共通節の扱いを `D-xxx` として決める。

## Q-013 検証データの封印をするか

**状態**: Open

**問い**: `D-008` の walk-forward 検証は、モデルを改善するたびに同じG1約240レースを評価に使う。**改善サイクルを繰り返すと、その240レースに対する成績は汎化性能ではなくなる**（事実上のテストセット汚染）。対策として、直近N年を最終評価まで一度も見ない形で封印するか。

**論点**:
- 封印しないと、開発終了時に「信じられる数字」が1つも残らない
- 封印すると標本がさらに減る。直近3年を封印すると評価用が約72レース、開発用が約168レースになる
- `architecture.md` 6.4 に「ハイパラ選択のオーバーフィット」として罠は記載済みだが、対策方針は未定
- 封印期間の長さ、および「何回まで開けてよいか」（原則1回）を決める必要がある

**必要な情報**: 許容できる標本数の下限。`D-008` の標準誤差の計算（`4/√n`）に照らして、封印後の評価用レース数で何が言えるかを見積もる。

**ブロックするもの**: `010-backtest.md` と `014-training-pipeline.md`。ただし方針だけ先に決めれば仕様は書ける。

**備考**: `Q-012` と同様、**後から決めると必ず甘い方に倒れる**性質のもの。
