## 設計の要点

- **対象**: JRA平地G1（年24競走前後）
- **目的**: オッズ非依存のファンダメンタルモデルを主軸に、市場確率を超えることを目標とする
- **学習範囲**: JRA全レース（約90万行）で学習し、G1に特化させる。G1のみでは約7,700行しかないため
- **モデル**: レース質予測 → 適性照合 の2段階構成。プロの「レースを先に、馬を後に見る」思考を写したもの
- **成果物**: CLI + バックテストレポート
- **スタック**: Python 3.12+ / Polars / DuckDB / LightGBM / uv（`D-042`）
